## 1. Pricing method

Unit price = landed unit cost ÷ (1 − target margin for the quantity tier), plus rush surcharge, adjusted for the sales channel, rounded up to the nearest Rp 500. Landed cost = blank cost + decoration run cost + setup spread over the run + packing, with 3% spoilage. Margin floor 15% (owner approval below). PPN added only when a rate is set (currently 0%).

| From qty | Target margin |
|---:|---:|
| 1 | 45% |
| 24 | 40% |
| 100 | 35% |
| 250 | 30% |
| 500 | 27% |
| 1000 | 25% |

**Sales channels**

| Channel | Rule | % |
|---|---|---:|
| Direct sales | discount off list | 0% |
| Corporate contract | discount off list | 5% |
| Reseller / agency | discount off list | 15% |
| Marketplace | platform fee grossed up | 10% |

**Brand design service levels**

| Level | Fee per job |
|---|---:|
| None (client artwork ready) | Rp 0 |
| Basic: artwork clean-up | Rp 150.000 |
| Standard: layout + 2 mock-ups | Rp 500.000 |
| Premium: merch brand concept | Rp 2.500.000 |
